# P08 最小单次生成切片

本任务采用 M00 Accepted、W0-T4 已接受名称/输入修订及 W1 v0.4 P08 字段。
原协议、Handoff、Prompt包和完整示例均不改，仍 Proposed。实施授权只含 P08，不含 Candidate Ethics/R0、Reflection、Ranking、Evolution。

## 输入与责任边界

`GenerationService` 独立于旧G3。USER 恰为以下六项，由存储事实组装，不接受客户端上传科学包：

| 字段 | 来源 |
|---|---|
| goal_context | 固定 P07 输入中的 Goal，与保存 Goal 比对 |
| seed_brief | 同一 seed 的固定 brief，与保存 seed 比对 |
| readiness_record | 已完成成功 P07 的完整 artifact，含 allowed_specificity、premise_gaps、hypothetical_unknowns |
| actual_frozen_seed_background_packet | P07实际检查的固定P05包，保留所有卡、视图、访问/裁剪及查询事实 |
| mode | 调用方选择 DIRECT / ASSUMPTION_STRUCTURED |
| candidate_id_from_caller | 调用方分配，不允许复用已预留身份 |

不读取示例候选、NegativeControlsReference、expected/critical_failures、Codex评审、兄弟seed或兄弟候选。公开示例仅作开发文档。
P07中“本次不进入生成”是原P07操作边界；本次授权允许新P08，但不改变其科学具体程度和前提限制。

只接受同Run/Goal/seed、同固定背景包的已完成ready；不能凭Run状态放行。retrieve_more、unable、未完成/无效/失败/uncertain不放行。
最新未解决外部Attempt阻断新生成；原uncertain经显式授权关联成功Attempt的情况沿用M15既有规则，原状态不重写。

## 单次方法、科学产物与限制

固定 Prompt `w1-p08-single-v1`。DIRECT与ASSUMPTION_STRUCTURED均一次调用、一个候选；后者的假设清单是简洁公开科学产物，不是思维链、多轮迭代或辩论，不宣称更优。
P08沿用字段：candidate_id/title/scoped_claim/biological_context/mechanism_steps/evidence_anchors/proposed_new_links/assumption_ledger/nearest_prior_work_scope/competing_explanations/predictions/falsification_conditions/validation_concept/limitations/source_refs。

本切片只细化这些必要局部形状：机制步骤标 source_observation_in_original_context / author_interpretation / new_conjecture；锚点绑定实际finding+view；必要假设有context_transfer/possible_check；预测有comparison/claim_prediction/alternative_prediction/readout；概念验证有setting/comparison/intervention_and_measurement/controls。
引用不能跨视图，不能漏列已引用来源；未提供源不得伪造。**结构和引用合法不证明科学正确或语义支持。**
Prompt要求保留情境、阴性和竞争解释，限定“当前视图未报告”；不得虚构位点/激酶/原文结论或未经核实参数，不把文献分子/模型升级为用户条件。
科学范围遵守、假说可行性和真实模型表现仍待真实输出及专家审阅；没有实现科学评价器或R0来保证这些要求。

## M12/M15、保存与恢复

新增一张小表generation_actions，固定request/candidate身份、六字段输入、绑定、模式/Prompt/配置；候选科学内容直接作为既有不可变Result保存，没有新候选服务。
`generation.P08`经既有Scheduler/TaskCalls执行。模型成功后结构无效或截断保存原响应/用量，结果invalid_output且不产生候选。
成功Result与Task应用沿用原事务/幂等机制，返回awaiting_candidate_ethics；没有后继科学任务，页面显示“已生成，待Candidate Ethics/R0”。
候选及ID不可通过支持的API修改；修改/新版本需新身份，失败任务的ID也已预留。数据库所有者直接SQL修改不属于受支持接口，非防篡改存储。

无配置或未获授权明确记录、不回退替身。完整请求超字节上限时capacity_exceeded、不发送、不裁剪。未知消耗仍null。
刷新/GET/重启不执行或recover。显式execute可恢复中断；保存成功调用本地回放，不重发。
uncertain必须操作者核实风险后用已有Store.authorize_uncertain_retry及retry_task，原Task/call_key/冻结请求恢复，不提供自动重试按钮或新身份绕过。

API：GET `/api/generation?run_id=...`，POST `/api/generation`（仅seed_id/readiness_ref/packet_ref/mode/candidate_id），POST `/api/generation/execute`，GET `/api/generation/attempt?attempt_id=...`。
保存与执行分开，失败/断网后任务仍可读；可从页面“显式执行/恢复”处理已保存或中断任务，blocked不会自动授权。

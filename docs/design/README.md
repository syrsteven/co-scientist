# Design sources

- `m00-accepted-v1.0/`: original M00 accepted architecture package, including its
  historical `reference/` material. Start with root files 01, 02, 03, 04, 06, 09.
- `w0-proposed-v0.1/`: both original W0 Proposed files. This implementation does
  not accept the entire proposal or implement its 14 scientific scenarios.
- `source-integrity.json`: SHA-256 of each input ZIP and every extracted file.
  File bytes and original statuses are preserved, including historical text about
  what had not been implemented when those packages were written.

The current user request authorizes W0-T0/T1 engineering implementation, beyond
those documents' historical design-only delivery statements. Its adoption is
limited to Project/BriefRevision/Run snapshots, scheduling, Task/Attempt/result
facts, actual I/O, errors, consumption, retries and recovery (W0-T0/T1), plus
fixed Admission references, separate qualifications, two-stage Delta and narrow
literature acquisition representations with structural counterexamples (W0-T2). M00 science rules
remain authoritative. Other W0 interfaces are future inputs.

See [current delivery status](../STATUS.md) and [runtime usage](../W0_RUNTIME.md).


W0-T3 preserves the two original files from `CoScientist_W0_Real_Cases_v0.1_PROPOSED.zip`
in `w0-real-cases-proposed-v0.1/`; integrity is recorded in
`w0-real-cases-source-integrity.json`. Original claims such as source verification
complete and independent primary study are preserved as attachment history, not
adopted as verified conclusions. See `../W0_REAL_CASES.md` for fresh checks and
review-only adoption corrections. This package and the M01/M02 proposal stay Proposed.

1. 当前用户在新聊天中明确确认的新决定，可以形成新的决策记录；与旧决定冲突时先列出差异。
2. 具体接口以**最新 accepted 的版本化契约和实际代码提交**为准；设计提案不能覆盖已实施事实。
3. 旧版 `00_COMMON_CONTEXT.md` 是背景快照，不是实时状态。
4. 论文未披露、仓库未实现的行为应明确标为拟议或待定。

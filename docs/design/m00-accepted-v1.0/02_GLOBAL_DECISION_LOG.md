## E. 变更控制

全局决定将来确有科学理由修改时，需新增 ADR（原ID、替代ID、科学理由、受影响模块、旧实验对比与新评测），不直接改历史决策记录；变更只作用于**新的研究执行或新候选**，已完成 Run 的评议与排名不因政策升级而静默变化。

M00不建立长期复杂治理平台；决策日志 + 模块版本交接 + 独立评测报告足够。用户已确认 F1/F2 和 A20–A23；Phase 3 RC2 设计整包已于 2026-11-01 验收。

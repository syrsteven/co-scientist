# Web Workbench v0.4 → 真实后端：验收场景

| ID | 场景 | 期望结果 |
| --- | --- | --- |
| A01 | 启动本地 Web 服务 | 仅 `127.0.0.1` 监听；五页可访问，健康状态准确，不依赖外部 CDN |
| A02 | 默认 G3 模拟研究 | 用网页创建、授权并启动真实 CoreRunner+MockTransport；COMPLETE，原生 FINAL_WINNER 及五项导出 |
| A03 | 无凭据 Mock | 可正常运行，0 次真实 provider/PubMed socket |
| A04 | prepared | 状态 prepared；events `[]`；export 被安全拒绝且不创建 DB |
| A05 | 浏览器刷新/关闭 | 后台任务持续，重开显示同一 Run 与正确进度/排名 |
| A06 | 并发或重复 start | 同一 Run 仅一个驱动；重复请求不增加 dispatch |
| A07 | SSE 重连 | 按 event sequence 补发，不丢/重复应用有意义科学事件 |
| A08 | 排名与分组 | μ 降序；σ、有效比较次数保留；不足有效比较的标为评估中；不编造分数 |
| A09 | 候选详情 | 原文、机制链、前提、预测、证伪、Ethics、Reflection、配对及谱系完整、对应来源 |
| A10 | PARTIAL / 尚未结束 | 无正式 FINAL_WINNER；best-so-far 明确标为临时 |
| A11 | 终止与恢复 | `stop` 不伪装 pause；终态不能继续；非终态仅原生允许时 resume |
| A12 | 当前快照及最终导出 | 五项 Native Trace 与原生一致；并发 busy 不发布混合结果 |
| A13 | 设置凭据 | PUT/清除、状态仅布尔/未验证；密钥不经 GET、不落浏览器持久存储、日志、事件、草稿、导出 |
| A14 | PubMed 邮箱 | 创建时冻结；修改设置不改变已创建 Run；错误邮箱返回可理解错误 |
| A15 | LIVE 授权 | 无用户明确确认不得派发；准确区分风险上限和实际费用；单 Run 授权不得转移 |
| A16 | 模型目录 | 只有后端已经适配验证的选项可真实运行；其他选项显示待适配与原因 |
| A17 | 非默认代数/预算 | 新 Config Builder 未验证前阻止真实创建，禁止自动改回默认或删除原生校验 |
| A18 | 目录安全 | 拒绝 `../`、绝对路径和伪造 run_id；不允许任意文件读写或浏览器自选数据目录 |
| A19 | 历史 Run / code identity | 旧版本身份不匹配时不恢复/导出，清楚告知用户使用旧环境 |
| A20 | 端到端离线自动化 | Python 3.12 pytest + 浏览器必要流程可复现，无真实模型/PubMed 请求 |

注意：成功完成 A01–A12 是最优先的 M1；A13–A15 属于 M2；A16–A17 的实际兼容扩大属于 M3。其余属于所有阶段必须满足的基础安全条件。
